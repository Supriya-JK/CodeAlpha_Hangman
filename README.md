# CodeAlpha_Hangman
A simple and interactive Hangman Game developed as part of my internship project. The game challenges players to guess a hidden word one letter at a time before running out of attempts.This project is created to strengthen my programming, problem-solving, and game-development skills during my internship.

1. About the Project:

The Hangman Game is a simple text-based Python game where the computer randomly selects a word from a predefined list. The player has to guess the word one letter at a time.
The player gets a maximum of 6 incorrect guesses. Correctly guessed letters are displayed in their positions, while unguessed letters are shown as _.

2.Concepts used:

The project is designed to practice basic Python concepts such as lists, strings, loops, conditions, user input, and the random module.

3.Features:

Interactive and user-friendly gameplay
Random word selection
Tracks correct and incorrect guesses
Limited attempts with a visual hangman progression
Displays win and loss messages
Simple and responsive design
